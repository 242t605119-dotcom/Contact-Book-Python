# Contact Book (Python)

## Project Description

A simple Python program used to save and manage contact details.

## Features

- Add Contact
- View Contacts
- Search Contact
- Delete Contact
- Exit

## Technologies Used

- Python

## How to Run

Run the following command:

python contact_book.py
